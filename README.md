# CATALYST Brand Assets

This repository contains the approved, canonical CATALYST — Region South logo files.

## Brand protection rule

Use these files exactly as supplied. Do not alter, redraw, modify, recolor, crop, trace, regenerate, or reinterpret the logo. Do not separate, rearrange, or recreate any element. Resize only in proportion, and adapt the surrounding layout to the logo—not the logo to the layout.
